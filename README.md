# Os Três Sinos

Hack-and-slash anime em terceira pessoa: o Rito dos Três Sinos, Dominação e partidas online com amigos.

## Como jogar
1. Baixe o arquivo `OsTresSinos_v*_Windows.zip` na versão mais recente em **Releases** (à direita).
2. Extraia a pasta inteira (botão direito → Extrair tudo).
3. Abra `OsTresSinos.exe`. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
4. No menu: **PERFIL → Conta** para criar seu usuário e salvar o progresso; **ONLINE** para criar uma sala e mandar o código para os amigos.

O jogo avisa no menu quando sair uma versão nova.
